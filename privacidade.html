Política de Privacidade

Última atualização: setembro de 2026

Este site é um canal de apresentação profissional de Sergio Augusto, engenheiro de software, baseado em Parobé/RS. Esta política explica quais dados são tratados quando você visita ou interage com esta página, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

01Quem trata os seus dados

O controlador dos dados tratados neste site é Sergio Augusto, profissional autônomo de desenvolvimento de software, com atuação em Parobé/RS. Para qualquer assunto relacionado a esta política, o contato é feito pelo WhatsApp (51) 99623-7698.

02Quais dados são coletados

Este site não possui formulário de cadastro. Os dados tratados se limitam a:

  • Dados de navegação: informações técnicas básicas do seu acesso (como tipo de dispositivo e páginas visitadas), usadas apenas para entender o funcionamento do site.
  • Dados de contato: quando você opta por falar por WhatsApp, Instagram ou Facebook a partir dos links deste site, o que é conversado nessas plataformas passa a ser tratado pelas políticas de privacidade delas, não por este site.

03Cookies

Este site utiliza cookies para lembrar que você já viu e aceitou este aviso, e para fins estatísticos básicos de funcionamento. Você pode gerenciar ou apagar cookies diretamente nas configurações do seu navegador a qualquer momento — isso pode fazer com que o aviso de cookies volte a aparecer.

Ao continuar navegando após aceitar o aviso de cookies na página inicial, você concorda com o uso descrito nesta política.

04Compartilhamento de dados

Nenhum dado coletado por este site é vendido ou compartilhado com terceiros para fins de publicidade. Os únicos compartilhamentos possíveis ocorrem quando você mesmo inicia contato pelas redes sociais ou WhatsApp vinculados no site.

05Seus direitos (LGPD)

Você pode, a qualquer momento, solicitar:

  • Confirmação de que seus dados estão sendo tratados;
  • Acesso, correção ou exclusão de dados pessoais eventualmente conversados via WhatsApp ou redes sociais;
  • Informações sobre com quem seus dados foram compartilhados.

Para exercer qualquer desses direitos, basta enviar uma mensagem pelo WhatsApp (51) 99623-7698.

06Segurança

Este site é hospedado em infraestrutura com práticas padrão de segurança. Nenhuma transmissão pela internet é 100% livre de risco, mas nenhum dado sensível é armazenado neste site.

07Alterações nesta política

Esta política pode ser atualizada periodicamente para refletir mudanças no site ou na legislação. A data no topo desta página indica a última revisão.
